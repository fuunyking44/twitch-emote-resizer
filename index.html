What sizes does Twitch actually require?

Every Twitch emote needs three files, uploaded together. If one size is missing or over the limit, the upload fails — which is why most people end up resizing the same image three times.

FileSizeWhere it shows
Large112 × 112Emote picker, channel page, hover cards
Medium56 × 56Chat on desktop
Small28 × 28Chat on mobile and in compact mode

Format must be PNG, each file under 1 MB, with a transparent background. Twitch renders emotes on both light and dark chat themes, so a white square behind your art will look broken for half the viewers.

How to upload the files to Twitch

  1. Open your Creator Dashboard and go to Viewer Rewards → Emotes.
  2. Click Upload Emote and pick the tier (subscriber, bit, or follower emote).
  3. Select all three files at once — 112, 56 and 28 — in the same dialog.
  4. Name the emote using the code viewers will type in chat, then submit for review.

Approval usually takes a few days. Rejections are almost always about transparency, file size, or the art containing text that breaks the emote guidelines.

Questions

Does this tool upload my image anywhere?

No. Everything runs in your browser with the canvas API. There is no server, no storage, and no account. You can even load this page, disconnect from the internet, and it still works.

Why does my emote look blurry at 112x112?

Because the source was smaller than 112 px and got stretched. Start from at least 112x112, ideally 224x224 or larger, so every output is a downscale instead of an upscale.

Can I use a GIF?

Animated emotes need frame-by-frame processing, which this page does not do yet — it takes the first frame of a GIF. Export a static frame for now, or use a dedicated GIF tool for animated ones.

What about Discord stickers?

Switch to the Discord tab. Stickers are 320x320, under 512 KB, and also need a transparent background. Same upload, different size.

Do I need to keep the same art for all three sizes?

Yes, Twitch treats them as one emote. Some creators redraw the smallest size by hand to keep details readable at 28 px — that is optional, but it does make a visible difference on mobile.
